=== HAUNT OS v1.0 ===

HAUNT OS - Minimal Operating System
Bootable ISO image for x86 PCs

Features:
- Custom bootloader
- Simple kernel with welcome message
- Text mode display

How to use:
1. Mount haunt_os.iso in your virtual machine (VirtualBox, VMware, QEMU)
2. Or burn to USB drive and boot on real hardware
3. The system will display a welcome message and halt

System requirements:
- x86 compatible CPU
- VGA compatible video
- At least 1MB RAM
